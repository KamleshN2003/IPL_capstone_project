# 🏏 IPL Capstone Project:https://iplcapstoneproject-aqgzwfvhau6mpq4jytwjhz.streamlit.app

## 📌 Project Overview

This project is an Exploratory Data Analysis (EDA) of the Indian Premier League (IPL) dataset using Python. The goal is to analyze IPL match data and extract meaningful insights through data cleaning, visualization, and statistical analysis.

---

## 🚀 Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Player Performance Analysis
- Team Performance Analysis
- Match Statistics
- Insights using Python Libraries

---

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/KamleshN2003/IPL_capstone_project.git
```

2. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open the notebook

```bash
jupyter notebook IPL_Capstone_Project.ipynb
```
